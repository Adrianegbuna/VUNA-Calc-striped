Adrian Calculator

A stripped scientific calculator with unit converter, built with modern DevOps practices — CI/CD, automated testing, Docker containerization, and continuous deployment.

⚡ HTML5 & CSS3 🔧 JavaScript 🧪 Jest Testing 📦 Docker 🔄 GitHub Actions ☁️ FTP Deploy
🔢

Core Calculator

Stripped-down arithmetic engine with addition, subtraction, multiplication, and division. No eval() — custom tokenizer and shunting-yard algorithm for safe expression evaluation.

🔄

Unit Converter

Custom feature: Convert between mass (kg, lb, oz), area (sqm, acre, ha), and data storage (GB, MB, TB, bits, bytes) with real-time results.

🚀

CI/CD Pipeline

Fully automated: Lint → Test → Docker Build → FTP Deploy. Every push to main triggers the entire pipeline automatically.

DevOps Pipeline

1
CI — Lint & Test

ESLint checks code quality. Jest runs unit tests with 80%+ coverage gate.

2
Docker — Build & Push

Multi-stage Dockerfile builds production image and pushes to Docker Hub registry.

3
Deploy — FTP to Live Server

Static files deployed automatically to cPanel shared hosting via FTP.
